I've been building software **professionally since 2017 (8+ years)**, with a backend-heavy
full-stack focus on **.NET** and scalable web platforms. My craft has evolved: instead of
typing every line, **I design the system and direct AI agents to build it** — spec-driven
development, multi-agent workflows, and rigorous review & verification. Years of hands-on
engineering are exactly what make that work — I can hand the AI the right architecture and
tell, immediately, whether its output is correct.

I care about clean, maintainable code, performance, and software that actually moves the
business — not demos.

### 🤖 How I build today
- **Architecture first** — I turn vague requirements into concrete specs and data models, then plan the build.
- **AI orchestration** — I drive AI coding agents through planned, multi-step workflows instead of writing boilerplate by hand.
- **Review & verify** — every change is read, tested, and verified before it ships. AI accelerates me; it doesn't replace judgment.

### 🚀 What I've built
- 🏢 **Enterprise SAP Business One reporting platform** (ABP / .NET + Next.js) — end-to-end integration over **SAP B1 Service Layer** and **direct HANA SQL**.
- 🧩 **No-code visual query builder** — a node-based, "blueprint"-style report designer with JOINs, nested AND/OR filters, multi-database `UNION ALL`, and on-the-fly query-complexity (Big-O) estimation — built for users who don't know SQL.
- 🔄 **Metadata sync engine** — a **.NET Aspire + RabbitMQ** background pipeline that tracks column add/change/delete across ~20 company databases.
- ⚙️ **Dynamic configuration system** — per-schema column visibility, display-name mapping, and UDF/UDT handling across the whole database fleet.
- 📊 **Self-service dashboards** — turning saved reports into Jira/Power BI-style dashboards, with Excel/CSV export.
- 🧱 **Reusable .NET microservice template & API gateway** — OpenAPI, localization, and SonarQube quality gates baked in.
- 🤝 Earlier, I helped build the **core platform of a fast-growing startup** through its scale-up phase.
